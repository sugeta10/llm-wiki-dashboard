# OpenAI Prompt Optimizer

OpenAIが提供するプロンプト改善専用ツール。プロンプトを貼り付けるだけでAIが自動的に最適化してくれる。

## 概要

**メタプロンプティング**の実装例の一つ。AIにプロンプトを作らせる手法そのものを自動化したツール。

- URL: OpenAI Platformから利用可能
- 対象モデル: GPT-5.4等、最適化したいモデルを選択して使用
- 利用条件: 有料プランのみ利用できるモデルあり

## 使い方

1. テキストボックスにプロンプトを貼り付ける
2. 画面左上でどのモデルに最適化するか選択
3. チャット欄に課題・要望を記載（例: Markdown形式で出力してほしい、期待結果と現実のギャップ等）
4. 「Optimize」をクリック

## メタプロンプティングとの違い

手動のメタプロンプティングでは以下のようなプロンプトを自分で書いてAIに渡す必要がある：

```
プロンプトを最適化するよう求められたときは...
以下がプロンプトです：{プロンプト全文}
期待される振る舞いは{期待}ですが、実際には{現実}を行っています。
最小限の編集・追加を行いますか？
```

Prompt Optimizerはこのプロセスを専用UIで自動化したもの。
