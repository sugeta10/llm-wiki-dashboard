# 動くAIスライド（クリックで深掘りできる資料）

> **TL;DR**: AIスライドを、押すと根拠のグラフが開き・スライダーで再計算される「動く資料」として出力させる手法。どう動かすかはスライドの論理構造（6種）から1対1で決め、1ページに動きは1つに絞る（@uchita_success）。

会議で「その内訳は？」と聞かれて資料を探す数十秒の空白を、資料側に答えを仕込んでおくことで消すのが狙いだと @uchita_success は述べる。同氏は、AIスライドの次の進化は「作る速さ」ではなく「見る人の体験」で起きると主張している。出力先は Claude のアーティファクト、ChatGPT のキャンバスかファイルで、記事の見本は Claude Opus 5.5 で作ったとされる。

## 見る人に起きる3つのこと

@uchita_success が挙げる効果は次の3つ。

1. **その場で詳細がわかる** — 数字を押すと裏付けのグラフが開き、「で、その内訳は？」に資料が答える
2. **情報のつながりが見える** — 1ページ目を全体像にし、カードを押すとそのページへズームして入る。O キーで全ページを並べると、見出しだけで話が一本につながっているのが見える
3. **動きで一目でわかる** — 記事の見本（物流の拘束時間）では、2024年度の帯が2025年度へ縮み、減った分が残る動きで「減ったのは運転ではなく荷待ちと荷役」が説明前に伝わる

## 構造 → 動きの対応（6構造）

記事の中心主張は「動かし方はセンスで決めない」こと。@uchita_success によれば、コンサル資料は言いたいことの形で6つの構造に分かれ、構造が決まれば付ける動きも1つに決まる。その動きは「見出しの主張を、見る人が自分の手で確かめられる」ものとされる。

| 構造 | 動き |
|---|---|
| 結論と根拠 | 押すと根拠が出る |
| 切り口 | 切り替えると並び替わる |
| 差分 | 形が変わり、差が残る |
| 原因と結果 | 条件を動かすと計算し直す |
| 不足と打ち手 | オン・オフで不足が埋まる |
| 流れと時間 | 順に組み上がる |

加えて「1ページに動きは1つだけ」がルール。動きが資料の構造どおりなので見る人が迷わず、「派手なだけでは？」という批判への答えにもなる、と同氏は述べる。

同じ著者の [[design/ai-slide-creation]] の「6構造型」（順番・対比・仕分け・問題と打ち手・原因と結果・結論先出し）とは分類の切り方が一部異なる（差分・切り口・不足と打ち手が新しく現れ、仕分け・順番は見当たらない）。本記事の6構造は「動きを決めるための分類」として組み直されたものと考えられる。

## 作り方

@uchita_success の手順は、いつものプロンプトに1ブロック足すだけ。

1. コンサル品質の資料を作る同氏の「究極プロンプト」を貼る
2. その下に、資料を動かす部分のプロンプトを貼る
3. いちばん下に素材（数字と出所）を貼る
4. 出てきた資料を開く

動かす部分のプロンプトは、AIに見た目をそろえさせる手本として見本ページ1枚分のコードを含み、8,000文字以上ある。完全版は同氏の note 記事（https://note.com/uchita_success/n/nf8711b1dba37 ）に置かれており、プロンプト本文はこのソースでは未収集。
