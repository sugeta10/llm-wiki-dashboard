# Claude Code で「高額に見える」Webサイトを作る

> **TL;DR**: テンプレを使わずClaude Codeにフルコードを書かせ、デザイン品質チェックリストで自己採点しながら反復することで、エージェンシーが$5K〜$15Kで請ける水準の一枚もの高級サイトを一日で作る制作ワークフロー。

差別化の源泉はコーディング能力ではなく**ディレクション**——「高そう」とは何かを言語化し、的確にブリーフィングし、平坦な箇所に妥協せず押し返す力にある。Claudeが実行を担い、出力の質は与えるブリーフ・参照・反復回数に比例する。テンプレート（Wix/Squarespace）はどれも似た見た目になるが、ゼロからコードを書かせると独自性が出せる。これが「プレミアムバー」に届く核心理由。

## 「高額に見えるサイト」を構成する8要素（3グループ）

制作前にこの基準を決めておき、最後に自分のサイトを採点する。**この自己採点パスこそが、洗練された結果と凡庸な結果を分ける唯一の動き**。

- **Taste（趣味・方向性）**
  1. Point of view — ムードボードでなく明確なデザイン方向性
  2. Typography — 意図あるフォント選択（使い古された定番を避ける。特に **Inter** は「AI製」を即座に露呈させる）
  3. Color — 抑制。4〜5色まで、虹色にしない
- **Substance（実質）**
  4. Hierarchy — サイズで「1番目・2番目・3番目に読むもの」を示す
  5. Imagery — カスタムまたは説得力あるAI生成画像。ストック素材の安っぽさを避ける
  6. Copy — 抑制的で感覚的、人間が書いたような文章（形容詞の羅列でない）
- **Felt quality（体感品質）**
  7. Motion — カーソルエフェクト・マイクロインタラクションで「生きている」感じ
  8. Mobile — 縮小デスクトップでなくスマホ専用に設計

## ワークフロー（要点）

1. **Claude Code セットアップ** — 専用の空フォルダをワークスペースにする（Claudeは自分専用フォルダで最も良く動く）
2. **2つのスキルで底上げ** — [[concepts/claude-skills]] を2本入れる。Anthropic製 **frontend-design**（バックグラウンドで動き、使い古されたAIフォント/レイアウトを禁止）と、コミュニティ製 **UI/UX Pro Max**（[[tools/ui-ux-pro-max]]・多数のUIスタイル・配色・フォントペアをオンデマンド呼び出し）
3. **auto mode** をオンにし、逐一の確認なしに作業させる
4. **参照を集める** — Dribbble / Awwwards / Pinterest から好みのサイト3〜5枚をスクショ。趣味は言葉で説明するより見せる方が速い。**品質の8割はこの参照集めと次の明確化質問から生まれる**
5. **1プロンプトで構築** — デザインスキルを呼び、ブリーフと参照画像を添え、最後に「**ask me clarifying questions**（明確化の質問をして）」で締める。Claudeは名前・スタイル方向・セクション・コピー担当・技術スタック・アニメ強度などを質問し、**3つのスタイル方向をメニュー提示**する。ここでの回答がサイト全体になる——最重要の瞬間
6. **8項目で自己採点** — チェックリストを貼って採点させ、残課題を特定
7. **意図でバッチ指示** — 個別修正でなく「どう感じさせたいか」を伝えて一括変更を依頼（トークン節約＆一体感）。Claudeは意図を具体に落とすのが人間より上手い。その後セクションごとにモーション/カーソル演出を1つずつ
8. **画像** — カスタム写真が最良。なければAI生成（プロンプトはClaude自身に書かせる＝プロジェクト文脈を持つため一発で的中）。[[tools/claude-code]] にプロジェクト文脈があるのを活かす
9. **21st.dev** から実開発者製コンポーネントを Copy Prompt で取り込む。**Claudeはアーキテクチャを守る**——静的サイトにReact版を無断で入れず平HTMLで再実装する（本当にReactが必要なら受け入れる）
10. **コピー・フォント・モバイル** の仕上げ。レスポンシブ≠スマホ設計。専用パスを依頼
11. **公開** — 初年度ドメイン無料の格安ホスト（静的なら最安shared枠で十分、年$43程度）。zipはプロジェクトフォルダ「の中身」を固める（フォルダごと固めると一階層深くなり空白ページになる）
