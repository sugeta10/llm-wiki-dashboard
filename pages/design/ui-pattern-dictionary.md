# UIパターン辞典サイト

@kawai_design がXで公開した、UIデザインパターンを「名称×ミニチュア実物」で一覧できる辞典サイト。ハンバーガーメニュー・カンバン・OTP入力・ボトムシートなど108種類のUIパターンを1ページにまとめ、「あのUI、名前なんだっけ？」を一発で解決することを狙う。

デザイナー・エンジニアが実装や会話の中で見かけたUIコンポーネントの正式名称を思い出せないとき、名称からでなくビジュアルから逆引きできる点が実務上の価値になる。
