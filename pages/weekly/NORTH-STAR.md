# North Star Metric

> **「週に1回以上、過去のwiki知識が新しい問い・判断・行動に接続された回数」**

pages数・links数はサロゲートメトリクスに過ぎない。

## 計測イベント（手動check-inから開始）

| イベント | 記録方法 |
|---|---|
| weekly insight generated | wiki/weekly/ にファイルが存在する |
| weekly insight opened | （主観）読んだら ✅ |
| related page clicked | （主観）リンクを辿ったら ✅ |
| action accepted | 小アクションを実行したら ✅ |
| source revived (14d+) | 古いページに戻れたら ✅ |
| unconnected seed connected | Unconnected Seedsにリンクを貼ったら ✅ |
| query led to wiki update | クエリ後にページを更新したら ✅ |

## Weekly Check-in（毎週月曜・3分）

1. 先週のInsightsを読んだか？ (Y/N)
2. wikiの知識が行動・判断に繋がった瞬間があったか？ (Y/N + メモ1行)
3. 今週のNorth Starスコア（上のイベント合計数）: ___

## 目標

| 時期 | 目標スコア | 意味 |
|---|---|---|
| Month 1 | ≥ 1 | 週1回は知識が行動に接続される |
| Month 3 | ≥ 3 | 習慣として定着。wikiが「使われている」 |
| Month 6 | ≥ 5 | 知識が複利化し始めている |
