# 再帰的自己改善（Recursive Self-Improvement）

> **TL;DR**: AIがAI開発そのものを加速させ、究極的には次世代モデルを自律的に設計・訓練するに至る——その移行を「コードを書く→実験を回す→方向性を決める」という人間の役割の段階的縮小として捉える枠組み。

「AIが自分の後継機を作る」という最終形だけが論点ではなく、**そこに至る勾配がすでに観測されている**点が核心。AI開発は大きく*engineering*（コードを書く・インフラを立てる・訓練を監督する）と*research*（どの実験をやるか決める・結果を解釈する・次に試す案を絞る）に分かれる。現状、engineering では「underspecified な問題を渡せばモデルが解法を設計する」段階、research では「well-specified な実験の実行は人間に並ぶか凌ぐ」段階に達している。残る人間の優位は **research taste / judgment**——どの問題が重要か、どの結果を信じるか、いつ行き止まりかを見抜く判断——に集約されつつある。これが「今日のAI」と「自律的に後継機を設計するAI」を隔てる最後のギャップ。

重要なのは、進歩の大半が「ひらめき」ではなく**漸進的な汗かき作業**（スケールして→壊れた所を見て→直して→再試行）であり、それこそAIが得意とする領域だという観察。Edison の「天才＝1%のひらめき＋99%の汗」でいう汗の部分が自動化されつつある。研究進捗が主にツール・計算資源の関数（実験をどれだけ速く・並列に・短時間で回せるか）であるなら、taste が自動化されなくても**複利的な加速**は起きる。

ただし加速は均一でなく、**[Amdahl の法則](https://en.wikipedia.org/wiki/Amdahl%27s_law)**が支配する：一部を速くしてもボトルネックは未高速化の部分に移るだけ。Anthropic では大量のコードが流れた結果、**人間のコードレビューが新たなボトルネック**になった。組織がこのボトルネックを素早く発見・解消する能力こそ、今後最重要のスキルになりうる。

## 検証済み事実

- 2026-05時点: Anthropic がマージするコードの **80%超が [[models/claude-opus-4-8]] 系の Claude によって書かれている**（Claude Code の research preview 投入は2025-02、それ以前は1桁%台）。経営陣の公開推定では実験コード含め90%以上
- 2026 Q2: エンジニア1人あたりのマージ行数が2024比 **8倍**。2021–2024は横ばいで、2025（Claudeがコードを実行し始めた）と2026（長時間自律稼働）に2つの変曲点
- METR の time horizon（50%信頼で完遂できるタスク長）は**約4ヶ月ごとに倍増**（旧トレンドの7ヶ月から短縮）。Opus 3（2024-03）≒4分タスク → Sonnet 3.7（2025）≒1.5時間 → Opus 4.6 ≒12時間タスク
- SWE-bench は2年で1桁%台→飽和。CORE-Bench（研究再現）は2024の約20%→15ヶ月で飽和
- 訓練コード高速化タスク（目標・成功指標固定の研究ループのミニチュア）：Opus 4（2025-05）≒3倍高速化 → [[models/claude-mythos]] Preview（2026-04）≒**52倍**（熟練研究者は4〜8時間で4倍）
- 自動 Claude レビューの遡及分析：過去の claude.ai インシデント原因バグの**約1/3を本番到達前に検出できていた**はず
- weak-to-strong 監督のオープン研究（2026-04公開）：エージェント群が gap の **97%を800時間・約$18,000の計算資源で回収**（人間2名は約1週間で約23%）。ただし本番規模へは未転移、問題選定とスコアリングは人間
- 「次の一手」が人間より良いかの評価（n=129、人間の選択に改善余地ある場面を選定）：Opus 4.5（2025-11）51% → Mythos Preview（2026-04）64%
- Project Glasswing 初期数週間で Mythos Preview が世界の重要システムに**1万件超の高〜致命severity脆弱性**を発見（cyber防御のボトルネックが「発見」から「パッチ」へ移行）

## 観察ログ（未検証）

- 2026-06-05: Anthropic（Marina Favaro・Jack Clark）は「完全な再帰的自己改善は不可避ではないが、多くの機関の備えより早く来うる」と主張。3つの未来——(1) トレンドが S字で停滞しつつ現capabilityが普及、(2) 複利的効率化が続くが方向設定は人間（最有力と自認）、(3) 完全な再帰的自己改善でモデルが後継機を建造——を提示
- 「行数は質より量を測る不完全指標で、8倍は真の生産性向上の過大評価」と自らcaveat。130人調査の中央値はMythos Previewで約4倍の出力増と推定（真値はやや低いと見込む）
- 「Claude製コードは2025末は人間以下、現在は概ね同等、年内に厳密に上回ると予想」（社内の見立て、コンセンサスではない）
- 社員引用「約1年前から本格的にClaudify、自分でコードを書かなくなって約5ヶ月」「人間の比較優位は今のところ大きな絵を描き目先のタスクの枠を超えて考えること」
- 政策的含意: 検証可能な形での減速・一時停止の*選択肢*を持つべきと主張。ただし訓練ランはミサイルサイロより秘匿容易で、軍縮型の検証は他技術より困難
