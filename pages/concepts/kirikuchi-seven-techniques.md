# 同じ一文を7通りで書く「切り口の在庫」（川岸宏司の7技法）

> **TL;DR**: 文章力の正体は語彙や名言の量ではなく「同じ一文を何通りで書けるか」という切り口の在庫数であり、直球・特徴3リズム・再現VTR・他者引用・天秤対比・電卓・通訳の7技法を文章の目的で選ぶ、と経営者の代筆を1万本以上手がけたと述べる川岸宏司（DIL 共同代表 COO）が X の記事で説く。

川岸は記事の冒頭で、ゴーストライターという仕事の「あまり大きな声で言えない真実」として、経営者が言いたいことは突き詰めると「挑戦しろ」「言葉にしろ」「行動が先だ」「人を大事にしろ」「学び続けろ」の5個くらいしかない、と書く。この5個を1万本以上代筆しても「また同じ話か」と言われなかったのは文章の才能ではなく切り口を替え続けたからだ、と川岸は述べ、その手の内を「言語化力が低い人は、仕事ができない」という一文を7つの技法で7回書き換える形で示す。

## 7つの技法（例文はすべて川岸の記事からの転記）

1. **直球型（まっすぐ言う）**: 例「言語化力が低いと、指示・報告・相談の精度が下がり、業務効率に悪影響を及ぼします」。正しいが記憶に残らない、と川岸は言う。ただし謝罪文と障害報告だけはこの技法しか許されないとして、「心を動かしてはいけない文章」専用の技法と位置づける。
2. **特徴3リズム型（特徴を3連で畳みかける）**: 例「主語を抜き、理由を省き、具体例を考えない。それが"言語化をサボる人"」。この文は実測4.9万いいねを取った実物だと川岸は書く。3連の順番は「主語→理由→具体例」という文章が壊れていく順番そのままで、当てはまる人が段階的に増える設計なので読者のどこかで必ず胸がチクッとする。語呂の技術に見えて「網」の技術だ、とする。
3. **再現VTR型（あの日の現場を流す）**: 例「このまえ上司から『いい感じにしといて』と資料を渡されたのだけど、金曜18時に『なんか違う』だけが返ってきて、休日がなくなった」。取材でいちばん欲しいのは意見ではなくセリフで、「その時、なんて言われたんですか？」だけで30分聞くこともある、と川岸は書く。セリフと時刻があれば文章は勝手に動き出す。ただし長く、結論の前に読者が帰るし、最後に「発見」を置き忘れるとただのグチになる。
4. **他者引用型（教わった言葉で語る）**: 例「10代のころに教わった『言語化をサボる人は信用しない方がいい』という言葉、そっくりそのまま私の信念にしてる」。川岸は自分の X 投稿のいいね上位はほぼ全部この型だと明かす。言ったのは他人なので押し付け感が消え、自分を大きく見せずに説教ができる。7つの中でいちばんずるい、とする。ただし作り話は一発でバレ、盛った瞬間に言葉の重みごと消えるので、実話だけで戦えと念を押す。
5. **天秤対比型（二つ並べて選ばせる）**: 例「言語化力は依頼でわかる。高い人は『明瞭な言葉』で仕事を任せてくれるけど、低い人からは『察して』が漂う。前者が仕事なら、後者は占い」。経営者が好む型で、プレゼン資料の8割はこれで出来ていると川岸は体感を書く。二つ並べると構造が一瞬で伝わり、読み手に「自分はどっち側か」を突きつける踏み絵になる。使いすぎると「また二択か」と飽きられ、世界は白黒より灰色のほうが多い、と付け加える。
6. **電卓型（感情を数字に翻訳する）**: 例「曖昧な指示1回で『確認2往復と手戻り1回』が最低発生する。約30分の損…毎日なら年間120時間＝丸5営業日。つまり『察する』には、人件費がかかる」。人は正論では動かないのに損得なら動く日がある、と川岸は言う。ただし数字がひとつ雑なだけで電卓ごと疑われる。
7. **通訳型（知らない話を、知ってる世界に訳す）**: 例「ジェスチャーゲームで『当てられなかった側にキレる人』は存在しないと思う。伝わらない原因が、どう考えても動きのほうにあるから。一方で、言語化力が低い人がビジネスでやってるのも…ほぼこれ。察しなかった側が怒られる」。コツは例えを「自分の世界」ではなく「相手の世界」から拾うことで、ゴルフ好きにはゴルフで、料理をする人には台所で例える。営業がうまい人が無意識にやっている、と川岸は書く。例えが遠いとただの誤訳になる。

## 目的で選ぶ（川岸の対応表の転記）

| 文章の目的 | 技法 |
|---|---|
| 早く理解してほしい | 直球型 |
| あるあるで頷かせたい | 特徴3リズム型 |
| 情景で感情を動かしたい | 再現VTR型 |
| 説教臭さを消したい | 他者引用型 |
| 違いを一瞬で見せたい | 天秤対比型 |
| 損得で行動を変えさせたい | 電卓型 |
| 記憶に残したい | 通訳型 |

7つに優劣はなく目的との相性があるだけなので、書く前に1回だけ「この文章の目的は？」と自分に聞く、と川岸は勧める。

## 文章力の正体は切り口の在庫数

同じ一文しか書いていないのに、選ぶ技法で読後の温度が変わる。語彙を増やすより、名言をブックマークするより「同じ一文を何通りで書けるか」の在庫がそのまま文章力になる、というのが川岸の結論である。練習法は、自分がよく書く一文をひとつ選んで7通りに書き直すこと。切り口の在庫は語彙と違って今日から増やせる、と川岸は書く。川岸自身は直球型が今もいちばん苦手で、飾りたくなる・盛りたくなる・たとえたくなる職業病だと明かし、タイトルに「7つ」と数字を入れたのも電卓型の親戚だと種明かしする。
