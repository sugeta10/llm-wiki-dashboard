X アルゴリズム Phoenix（2026年5月改変）

2026年5月15日、X（Twitter）のアルゴリズムが大規模に改変された。ソースコードは GitHub の公開リポジトリ xai-org/x-algorithm で確認できる。

変更の概要

  • Grokベースの新システム「Phoenix」 が導入された
  • 従来の「いいね集め」や「量産投稿」によるバズは機能しなくなった
  • アルゴリズムの評価軸が根本的に変化している

実務的含意

旧戦略（非推奨） 新戦略
いいね数の最大化 エンゲージメント品質重視
量産投稿 少数・高品質投稿
リアクション狙いの投稿 ユーザーに価値をもたらす投稿

アルゴリズムが公開リポジトリで読めるため、仕組みを直接確認してコンテンツ戦略に反映することが可能になった。
