# マネージャーで止まる人と部長になれる人の差

> **TL;DR**: マネージャーと部長は管理職の延長でなく「役割の次元」が変わる——マネージャーが最初の2つの力（対人力・やり切る力）で足りるのに対し、部長には意識して鍛える「蓋然性を語る力」と「個性を使い分ける力」が加わる、という @kojiteshigawara の断絶論。

```mermaid
flowchart LR
  P["強いプレイヤー"] -->|"力1 ウェットな対人力<br/>力2 やり切る力<br/>（結果を出す過程で自然に身につく）"| M["マネージャー<br/>与えられた文脈を<br/>やり切る人"]
  M -->|"力3 蓋然性を語る力<br/>力4 個性を使い分ける力<br/>（意識して鍛える＝断絶）"| B["部長<br/>会社の文脈を作る<br/>＝役員候補生"]
```

@kojiteshigawara は、両者で「そもそも求められるものが違う」と言う。マネージャーは上から落ちてきた文脈の中でチームをまとめ結果を出す「現場をやり切る人」であり、文脈を作れればなお良いが、やり切るだけでも存在価値になれてしまう。対して部長は自分で文脈を作る側に回らなければ成立しない「役員候補生」で、ヒト・モノ・カネの制約の中で結果を出しながら部門全体の先を示す。そのうえで @kojiteshigawara は、断絶はプレイヤーとマネージャーの間より、マネージャーと部長の間のほうが大きい、という反直感的な主張を置く。

## 部長の4つの力

会社の文脈を作り進める役割に必要な力を、@kojiteshigawara は4つに分ける。

1. **ウェットなコミュニケーション力**: ロジックだけでは動かない人間を関係性の力で動かす。会議室では言えない本音を引き出し、根回しで事前に地ならしをする。「誰と・どんな場で・何を話すか」を場当たりでなく意図を持って設計できること。
2. **やり切る力**: プロジェクト推進なら何でもやる。ボトルネックを自分で特定して取り除き、専門家を外から連れてくる・経営層と直接向き合う。「自分の役割ではない」と役割の境界に逃げ込まない。
3. **蓋然性を語る力**: 先を決め、文脈を作り、「なぜそこに行くのか」の確からしさを作る力。@kojiteshigawara は、ビジョンを示すだけでは足りず、誰が反対するか・費用感・現場の業務がどう変わるかまで考え抜いて初めて人は動く、とする。単なる論理的説明力ではない。
4. **人の個性を使い分ける力**: 部下を自分のコピーとして扱わず、一人ひとりの強みを読んで役割を設計する。「A さんにはこれ、B さんにはこちら」と判断できること。

@kojiteshigawara の核心は、マネージャーになるだけなら最初の2つで足りる、という線引きにある。ウェットに人を動かし泥臭くやり切れる人はプレイヤーとして結果を出し、評価されてチームを持つ——強いプレイヤーがマネージャーになるのは自然な流れで、この2つは結果を出す過程で気づいたら身についている。断絶は延長線上にない残り2つにある。

**蓋然性を語れない人は感想しか言えない**、と @kojiteshigawara は言う。「経営の方向性はどうかと思う」「エンドユーザーを考えたらこうすべきだ」と正しいことを言える人は組織にたくさんいるが、「じゃあどうすればいいのか」が薄い。同じ会議室にいても、すでに対応方針を具体まで考え、反対しそうな人を読み、全方位にアイデアを当ててブラッシュアップしてから臨む人は、立っている地点が違う。心の中にはあるがアウトプットできていない・整っていないから巻き込めない——突き詰めるかどうかの差だ、とする。逆に言えば、実行力がそこまでなくても蓋然性を語れる人が部長に上がることがあるのは、それだけこの力が希少で組織の肝になるからだ、と @kojiteshigawara は指摘する。

**人を個性として見られない人はチームの天井になる**、というのがもう一つの差分だ。マネージャーの範囲なら似たタイプを集めて自分のやり方を通し、合わなければ異動させれば回る。しかし部長は営業・企画・オペレーションと多様な領域を同時に動かすため、同じタイプだけでは部門が回らない。マネージャーで止まる人には部下を「自分の劣化模倣品」として見て自分のやり方を押し付ける傾向があり、悪意でなくむしろ熱心さゆえにそうなる、と @kojiteshigawara は言う。プレイヤーとして優秀だった人ほど、自分の成功体験がそのまま押し付けになりこの転換が難しい。

## 問い

- 「蓋然性を語る力＝先を決め確からしさを作る」は、AIエージェント運用で「プロンプトで方向を決め、検証器で確からしさを作る」作業と構造的に同じか。人間の部下を巻き込む根回しに相当するものは、AI相手には何か。
- 「個性を使い分ける力」は複数のサブエージェントを役割で束ねるオーケストレーション（[[concepts/multi-agent-patterns]]）に流用できる発想か。
