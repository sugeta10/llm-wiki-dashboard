# 就寝前の委任プロンプト（8時間お願いプロンプト）

寝る前にバックグラウンド型エージェントへ「これから8時間不在にする」と宣言し、不在の間の進め方をまとめて委ねる一文プロンプト。@paji_a が [[tools/openai-dots]] 向けに「寝る前 Dots にこれ頼むと最高」として公開し、@hAru_mAki_ch がそれを「8時間お願いプロンプト」として改造した版を画像で投稿した。

@paji_a のプロンプトは、ポスト本文で読める範囲では次の指示を1文に束ねている（本文は「重要」の直後で途切れており、続きは添付画像にあって未収集）。

- これから8時間就寝すると宣言する
- 各セッションの残タスクを、**これまでの依頼・承認の範囲で**自律的に進める
- 利用可能なゴール設定や Dots の定期確認を使い、停止した未完了セッションを再開する
- 行き詰まったら別の解決方法へ切り替える
- 自分（ユーザー）の入力待ちは保留にして、他の作業を進める

この構成は、夜間に自律実行させるときの典型的な失敗（途中で止まる・1つの詰まりで全体が待つ・権限外の操作に踏み出す）を、それぞれ1項目ずつ先回りして塞いでいると読める（wiki側の解釈）。特に「これまでの依頼・承認の範囲で」という限定は、自律の範囲を新しく広げるのでなく既に与えた承認の内側に閉じる歯止めとして働くと考えられる。[[tools/hermes-agent-overnight]] が wakeAgent ゲートやセキュリティ層といった仕組み側で夜間実行を制御するのに対し、こちらは製品の機能（ゴール設定・定期確認）に乗ったうえで方針を自然言語1文で渡す、軽量な版にあたる。

@paji_a は同じ日の引用元ポストで Dots について「これ全年齢AGIじゃん」とも書いており、このプロンプトは Dots を専門知識なしで夜通し動かす使い方の例として広まったと考えられる。@hAru_mAki_ch の改造版の中身は画像のみで未収集。
