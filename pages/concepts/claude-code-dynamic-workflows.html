Claude Code Dynamic Workflows

claude-code の Research Preview 機能（2026-05-28発表）。プロンプトに「workflow」という単語を含めるだけでClaude自身がオーケストレーションスクリプトをその場で生成し、複雑なタスクを大量の協調サブエージェントに並列分散させて実行する。

  • Claude がオーケストレーションスクリプトをオンザフライで作成する
  • 大規模なサブエージェントフリートを並列起動して協調させる
  • プロンプトに「workflow」と入れるだけで起動できる（Research Preview）
  • multi-agent-patterns の Fan-Out / Orchestrator-subagent パターンをユーザー向けに抽象化したもの
  • 1つのセッション内で数十〜数百の並列サブエージェントを動かすことができる

使い方

  1. /config の Dynamic workflows が true になっていることを確認する
  2. プロンプトに「workflow」という単語を含めて指示を出す
  3. Claude が動的にオーケストレーションプランを作成し、厳密に実行する — 各ステージが正しい順序で処理されることが保証される

公式説明（@_catwu）: "Claude will dynamically create an orchestration plan that it strictly follows, allowing you to confidently trust that every stage happens in the right order"
