# 未完了タスクの疲労ループ（ツァイガルニク効果と「決着」）

> **TL;DR**: 「ずっと疲れている」の正体は体力不足ではなく、頭に残り続ける小さな未完了が注意を奪い続けることで、疲労が行動コストを高く見積もらせて未完了をさらに固定化する悪循環がある。抜け出す鍵は「完了」ではなく「決着（それについて何かを決めること）」だ、とする考え方。

```mermaid
flowchart LR
  A["小さな未完了"] --> B["注意を奪われ続ける"]
  B --> C["疲労感"]
  C --> D["行動コストを高く見積もる"]
  D --> E["後回し"]
  E --> A
```

@tsumugi_utatabi が、うつ病の経験をもとに X 記事「『低体力』だから仕事が続かない？うつ病になる人が陥りやすい『ずっと疲れてる』の正体」で書いた議論。寝ても食べても回復せず、休んでいる時間すらソワソワするという状態を、筆者は当初「体力のなさ」と疑ったが、後から原因は頭の中に残り続けていた「終わっていない出来事」だったと気づいたと述べる。

ここで言う未完了は一刻を争う危機ではなく、日常の隙間にへばりつく微小なものだ。筆者の挙げる例は、週明けに返すべき気まずいメール、「検討します」と言ったきり保留の案件、買おうとブラウザのタブに開きっぱなしの消耗品、通知を消しただけで返していないSNSのメッセージ、伝えそびれている誰かへの一言。心理学では完了した事柄より未完了・中断された事柄のほうを強く記憶し続けるとされ、これが**ツァイガルニク効果**として知られている、と筆者は紹介する。

## 悪循環の構造

筆者の説明では、未完了が1つでもあると頭の片隅で常にそれが「気にかかっている」状態が続く。これは集中している時間でも休んでいる時間でもなく、注意のリソースを中途半端に持っていかれ続けている状態で、この「注意を向け続ける」こと自体が疲労感を生む。

問題は次の段で、疲れた状態の人はあらゆる行動のコストを高く見積もるようになる、と筆者は言う。普段なら5分で終わることが「ものすごく面倒なこと」に感じられ、「もう少し元気なときにやろう」と後回しにされる。こうして、放置された未完了が注意を消費し、注意の消費が疲労を増やし、疲労が行動コストの見積もりをさらに上げる。筆者はこれを「未完了が疲労を生み、疲労が未完了を固定化する」とまとめ、ツァイガルニク効果がもたらす苦悶の正体だとしている。「さっさと終わらせればいい」が通用しないのは、すでにこのループの内側にいるから、という整理になる。

## 求めているのは「完了」ではなく「決着」

脱出口として筆者が示すのは、未完了が頭にこびりつく原因は「終わっていないこと」ではなく「それについて何も決めていないこと」だという見方で、脳が求めているのは完了ではなく**決着**だと述べる。具体的な解決法は note 記事への誘導になっており、本vaultには未収集。

「決着」は、やらないと決めたことに見直し日をつけて棚に上げる [[tools/taskmd-shelf]] の「積極的棚上げ」や、不安をノートに書き出してワーキングメモリを解放する [[concepts/mental-conditioning]] の認知的アンローディングと同じ方向の手と考えられる（推論）。どちらも、タスクを終わらせずに「扱いを決めて頭の外に置く」ことで注意の占有を外す。一方、[[business/human-nature-persuasion]] では同じツァイガルニク効果が「着手させると解消への緊張が生まれ、続けたくなる」という行動を起こす側の力として使われており、同じ効果が文脈しだいで推進力にも消耗源にもなる点は対照的だと考えられる（推論）。

## 問い

- note 記事の具体的な解決法を取得し、「決着」の中身（棚上げ・期限設定・やらない宣言など）が GTD 系の手法とどう違うかを確かめる
- 自分の未完了（開きっぱなしのタブ・保留した返信）を1週間書き出し、「決着をつけた」ものと「終わらせた」もので疲労感の変化に差が出るかを試す
- ツァイガルニク効果の「未完了のほうがよく記憶される」という元の知見が追試でどこまで再現されているかを確認し、疲労との因果まで主張する本記事の議論のどこまでが研究でどこからが体験談かを切り分ける
