AIコーディング言語ベンチマーク（Claude Code版）

claude-code に13言語で簡易 git を実装させ、時間・コスト・成功率を定量比較した実験（mametter/Zenn、2026-03 実施）。Ruby・Python・JavaScript が最速・最安で、静的型付け言語は 1.4〜2.6 倍コスト増の傾向。

関連: claude-code / agentic-coding / vibe-coding

観察ログ（未検証）

  • 2026-05-20: 速さの原因として著者が挙げた仮説（複合的と推測）: ①型システムの有無（動的型付けが有利）、②短く簡潔に書けること、③AIの習熟度（Python/Ruby/JS はトレーニングデータが豊富）、④言語固有の難しさ（C のメモリ管理・Rust の所有権）
  • 2026-05-20: LOC が少なくても速いとは限らない。OCaml・Haskell は行数最少クラスだが時間・コストは中位以下。思考トークン消費が多い可能性
  • 2026-05-20: 時間 ≒ コストの散布図が示す通り、所要時間とコストはほぼ比例する
  • 2026-05-20: 型なし動的型付けでもテスト外パスの型エラーリスクはある。ただし型エラーは検出しやすいバグで、検出しにくいロジックバグが同程度に混入するなら型検査の有無以前の問題では、という著者の見解
  • 2026-05-20: 差は最大2倍程度だが、プロンプト→待ち→次タスクのサイクルを高頻度で繰り返す実開発では体感差・集中力的に大きい、との著者主張
  • 2026-05-20: 将来的に「初期は動的型付けでスピーディーに開発 → 仕様が固まったら静的型付けに移行」戦略がより現実的になる可能性。コーディングエージェントは言語移植に強い印象があるため

検証済み事実

  • 2026-05-20: 実験条件: Claude Opus 4.6 (high effort)、各言語20回試行、タスクは2段階（v1=新規作成、v2=機能拡張）
  • 2026-05-20: 600回実行中テスト失敗は3回のみ（Rust 2回・Haskell 1回）
  • 2026-05-20: 平均コスト上位3言語: Ruby $0.36、Python $0.38、JavaScript $0.39（v1+v2合算）
  • 2026-05-20: 平均コスト下位3言語: Ruby/Steep $0.84、Haskell $0.74、C $0.74
  • 2026-05-20: 所要時間上位3言語: Ruby 73.1s±4.2s、Python 74.6s±4.5s、JavaScript 81.1s±5.0s（標準偏差も最小）
  • 2026-05-20: 静的型付け言語の倍率（対 Ruby）: Go 1.4倍、Java 1.6倍、Rust 1.5倍、TypeScript 1.9倍、C 2.1倍、Haskell 2.4倍、Ruby/Steep 2.6倍
  • 2026-05-20: v1（新規作成）では言語差が大きく出る。プロジェクト設定ファイル（Cargo.toml等）の生成コストが影響している可能性
  • 2026-05-20: 実験コード・結果は GitHub (mame/ai-coding-lang-bench) で公開。実行ごとの生成コードも data ブランチに公開
