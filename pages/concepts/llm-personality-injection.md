# LLMへの性格注入（Personality Injection）

MBTIなどの性格モデルをプロンプト/システムプロンプトに組み込むことで、**再学習なしにLLMの振る舞いを大幅に変化させる**手法。

## MBTI × LLM 研究

`@kosuke_agos`（2025-09-26）が紹介した研究によると：

- MBTIの16タイプをシステムプロンプトで指定するだけでAIの応答スタイルが激変
- 高コストなファインチューニング・再学習は不要
- 個人・プロダクトによって最適な「性格」が異なるため、用途別カスタマイズが可能

## 応用パターン

| 用途 | 推奨タイプ例 |
|------|------------|
| 厳密なコードレビュー | INTJ（独立・戦略的） |
| ユーザーサポート | ENFJ（共感・協調） |
| ブレインストーミング | ENTP（発散・議論好き） |
| 技術文書作成 | ISTJ（慎重・系統的） |
