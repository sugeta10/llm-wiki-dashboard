AI企業の垂直統合と受託業界への影響

fladdict（深津貴之 / note CXO）による分析（2026年5月）。openai の Deployment Company 設立・anthropic の企業向け AI サービス会社設立という動きを受けた産業構造の変化考察。

核心：「APIを売る」から「AIで御社を変革する」へ

OpenAI・Anthropic がモデル API の提供にとどまらず、FDE（Forward Deployed Engineers） を企業内に常駐させ、業務の中核に AI を組み込む会社を設立し始めた。

なぜ新産業でなく既存産業へ？

新しい産業を作るより、すでにお金が流れている業務に入る方が合理的：

  • 顧客・法律・稟議フローはすぐには変わらない
  • 金融・セキュリティ・法務・会計・医療事務・バックオフィスは「地味だが固い」
  • ビッグテックはすでに巨額設備投資済み → マネタイズを確実にする必要がある

コンビニのプライベートブランド戦略との類比

  1. まず API を開放し、どの業界・業務で AI が効くかデータを集める
  2. 儲かるカテゴリが判明したら自社で直接参入（合弁・買収・FDE派遣）
  3. 業務を吸い上げ、再利用できる部分をプロダクト化

棚を貸す側 → PB化する側へのシフト。

日本のSI業界への影響予測

NTT・ソフトバンク・KDDI・NEC・fujitsu・SCSK・TIS・アクセンチュア・デロイト・PwC・ベイカレントなど大手が、ビッグテックと組んで国内版 Forward Deployment 会社を作りにいく。

椅子の数は限られている：

パターン 結果
組めた大手 SI 最新モデル・ノウハウ・事例・人材採用で優位
組めなかった大手 SI 買収・下請け化・ニッチ撤退・縮小
中小受託 ドメイン知識会社として買収対象、職位単位では消滅リスク

買われるなら早いほうが高い。 標準化が進むほど買収価値は下がる。

「ドメイン知識があるから大丈夫」の落とし穴

短期では正しいが、資本の視点では別の手がある：

「ドメイン知識を持っている会社を買い、現場を観察し、業務を棚卸しし、暗黙知を形式知にし、データ化し、モデルを注入する」

AIに置き換わらない仕事 → AIから呼び出される外部モジュールになる。
ラストワンマイルの会社を買って API 接続し、AI エージェントの外部スキルにするという手が来る。

会社は残る。でも職位は残らないかもしれない

自動適応製品（「この業界の最新ベストプラクティスに合わせて」くらいで設定変更が完了するもの）が出た瞬間に発注は激減する。

受託が忙しい時期は、たぶんしばらく続く。でも、それは需要増ではなく、終わりの前の移行需要かもしれない。

エンジニア・PM・デザイナーの生き残り戦略

「AI でできない作業」を探すのは時間稼ぎにすぎない。目指すべきは：

AIを含んだシステム全体の責任に近づくこと

  • エンジニア: コードを書く人 → 業務を計算可能にする人
  • PM: 要件をまとめる人 → 変化の順番を設計する人
  • デザイナー: 画面を作る人 → 人間が AI を信頼・監督・修正できる関係を作る人

自分自身を自動更新する：昨日の自分の仕事を今日の自分が AI で奪えるか。毎週少しずつ作業を AI に渡し、浮いた時間で顧客・意思決定・業務・資本に近づく。

守るべきは職位でなく資本

3種の資本を積む：

種別 内容
人的資本 AI・業務・事業・デザイン・技術を横断して学び続ける
社会関係資本 顧客・仲間・専門家・経営者・現場との信頼関係
金融資本 再編時に不利な選択をしなくてよい余裕

ソブリンAI は万能ではない

国策 AI も資本集約は起きる（グローバル → 国内大手への集約に変わるだけ）。かつ「安全保障用の劣位 AI を持ちつつ、日常業務には高性能な海外 AI を使う」二重構造になる可能性が高い。

メタレベルの問い

自社は棚を持つ側か、棚に置かれる側か。
AI を呼び出す側か、AI に呼び出される外部モジュールか。

agi-knowledge-moat と同じ問い：AGI時代に競争優位は「知識の占有」から「ポジション」に移る。
