役割別Agent Skillsコレクション6選

@RoundtableSpace が、エージェント用スキルのGitHubリポジトリを職種の役割別（SENIOR ENGINEER / PRODUCT DESIGNER）に分けて紹介した厳選リスト。ポスト本文はリポジトリ名とリンクのみの短文だが、「エンジニア向け」と「デザイナー向け」を分けて提示するキュレーション軸は、スキル集を機能別でなく使う人の職能別に束ねる見せ方で、claude-code-github-repos（@heynavtoor の10選・順位型）とは切り口が異なると考えられる。

紹介されたリポジトリ（ポストからの転記）:

役割 スキル名 リポジトリ
SENIOR ENGINEER Superpowers github.com/obra/superpowers（superpowers）
SENIOR ENGINEER Agent Skills github.com/addyosmani/agent-skills（addyosmani-agent-skills）
SENIOR ENGINEER Karpathy Skills github.com/multica-ai/andrej-karpathy-skills（claude-md-rulesの正本リポ）
SENIOR ENGINEER GStack github.com/garrytan/gstack（gstack）
PRODUCT DESIGNER UI UX Pro Max github.com/nextlevelbuilder/ui-ux-pro-max-skill（ui-ux-pro-max）
PRODUCT DESIGNER Taste Skill github.com/Leonxlnx/taste-skill（taste-skill）

ポストには7つ目として「Impeccable」の名前も挙がっているが、リンクはポスト内に記載がない。

エンジニア側の4本はすべて当wikiに詳細ページがある（Superpowers＝開発方法論のスキル化・GStack＝バーチャルエンジニアリングチーム化・Agent Skills＝addyosmani-agent-skills・Karpathy Skills＝claude-md-rulesの正本リポ）。デザイナー側の UI UX Pro Max も個別ページ化した（ui-ux-pro-max）。claude-premium-website-build の制作ワークフローで品質チェックに使われているスキルと同名で、機能記述（UIスタイル・配色・フォントペアのオンデマンド呼び出し）もリポジトリREADMEの内容と一致するため、同一を指すと考えられる。
