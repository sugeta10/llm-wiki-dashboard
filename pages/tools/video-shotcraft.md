# video-shotcraft

**video-shotcraft** はClaude Code / Codexを「モーションデザインスタジオ」に変えるAIエージェントスキル。106のショットレシピカード・162スタイル・161のモーションプレビュー・本番運用可能なテンプレート「Ink Press」を同梱し、[[tools/remotion]] を使ってシネマティックなプロダクトプロモ・マーケティング・ローンチ・デモ動画を組み立てる。

作者Vincentwei1021によれば、ショットレシピの多くはClickUp・Perplexity・Slack・Notion・Figma・Framer・Bear・Raycast・Pitch・Miro・Superhuman・Loomなど著名プロダクトの公式プロモ映像のモーション言語（タイミング・イージング・振り付け）を研究して抽出したもので、素材・作品自体は含めずゼロから再実装している。

## 構成

| 内容 | 説明 |
| --- | --- |
| ショットレシピカード106枚 | 目的・エネルギー・推奨尺・パラメータ・実装ノート・既知の落とし穴 |
| モーションプレビュー161本 | 162スタイルをカバー、オンラインGalleryで検索・絞り込み可能 |
| Remotion実装 | 各カードのイージング・タイミングを含むチューニング済みTSXデモ |
| 完成テンプレート「Ink Press」 | 36.2秒・1920×1080・30fps・10ショット、2.5Dリアルページカメラ・タイトルカード・トランジション・SFXパスを含む検証済み構成 |
| コンポーネント・アセット | 2.5Dページカメラ・キャプション・フラッシュカット・デジタルロール・SFX・キャプチャスクリプト |
| 制作方法論 | キャプチャ・ビジュアルディレクション・ストーリーボード・サウンドデザイン・ビートシンク・最終QA |

リポジトリ構成は`SKILL.md`（エージェントのエントリポイントと制作ルール）を起点に、`references/`（パイプライン・ショットカード・シーケンス・ビジュアルQA基準・BGM解析・サウンドデザイン）、`demos/`（Remotion参照実装）、`gallery/`、`template/`、`assets/`に分かれる。

導入は「このリポジトリをスキルとしてインストールして」とエージェントに伝えるか、`npx skills add Vincentwei1021/video-shotcraft`、またはクローンして`~/.claude/skills/`にシンボリックリンクする。
