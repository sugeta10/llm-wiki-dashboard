Claude Code サブエージェント

claude-code のサブエージェント機能。専用のコンテキストウィンドウで独立して動作し、メインエージェントのコンテキストを汚染せずに作業を完了して結果だけを返す。

観察ログ（未検証）

  • 2026-04-26: サブエージェントは .claude/agents/ または ~/.claude/agents/ に Markdown ファイルとして定義する。frontmatter（description など）を Claude Code が自動検出し、タスクが説明に一致すると起動する
  • 2026-04-26: 優先度は「プロジェクトローカル（.claude/agents/）> グローバル（~/.claude/agents/）」。同名の場合は高優先度が勝つ。チーム共有はプロジェクトローカル、個人用途はグローバルが推奨
  • 2026-04-26: 長いセッションでは grep・find・ls などのツール呼出がすべてコンテキストに残り、30分で 80k トークンのノイズが生じる。/compact 時に重要情報が圧縮で失われる問題をサブエージェントが防ぐ
  • 2026-04-26: デフォルトのサブエージェントは空コンテキストで起動（クリーン）。CLAUDE_CODE_FORK_SUBAGENT=1 で親コンテキストの完全コピーを引き継いでフォーク起動できる
  • 2026-04-26: /fork スラッシュコマンドでオンデマンドのフォーク。フォークされたサブエージェントは親と プロンプトキャッシュプレフィックスを共有し、2番目以降の子は入力トークンが約10倍安くなるとされる
  • 2026-04-26: context-timeline フック（https://www.aitmpl.com/component/hook/monitoring/context-timeline）でメインエージェントと並行動作中のサブエージェントのコンテキストをリアルタイム表示できる

検証済み事実

  • 2026-05-23: Claude Code のフォルダ構造に ~/.claude/agents/ と .claude/agents/ が存在することは claude-code のフォルダ構成セクションで公式に確認済み
  • 2026-05-23: built-in サブエージェント Explore（コードベース検索）と Plan（実装計画立案）が Claude Code に同梱されていることは claude-code の記述と一致する

Built-in サブエージェント

サブエージェント 役割
Explore コードベース検索（grep/find 系）を独立コンテキストで実行。関連箇所だけを返す
Plan ファイル読込・アーキテクチャ理解・実装計画を作成。中間ファイル読込がメインに入らない

コンテキストフォーク

export CLAUDE_CODE_FORK_SUBAGENT=1

設定後はすべてのサブエージェントがデフォルトで親コンテキストを継承。オンデマンドは /fork コマンドを使う。

フォークされたサブエージェントの特性： - 親の会話全体をフォーク時点で継承 - 親とプロンプトキャッシュプレフィックスを共有（2〜N番目の子は約10倍安い） - ツール呼出は親のコンテキストに入らない - 最終サマリーのみを親に返す
