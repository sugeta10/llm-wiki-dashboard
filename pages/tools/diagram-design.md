# diagram-design

AIに図を描かせると「なんか全部よくある箱」になる——その見た目の問題に絞って作られたGitHubリポジトリ（`cathrynlavery/diagram-design`）。紹介者の@trendtech33566は特徴を4点挙げる。

- **27種類の図に対応** — アーキテクチャ図やフロー図など
- **HTML + SVGだけで完結、ビルド不要** — 追加のツールチェーンを持ち込まない
- **サイトを読んで色やフォントを寄せ、ブランド感まで合わせる** — 対象プロダクトの見た目に図を揃える
- **「Figmaで微調整地獄」を避けやすい** — 生成後に手で整える工程を減らす

同氏は技術記事・設計資料・プロダクト紹介など、図の見た目までこだわりたい用途に刺さるとする。出力がHTML + SVGである点は [[concepts/html-output-format]]（Anthropicが説く「LLMの出力フォーマットとしてのHTML」）と同じ賭けであり、ブランドの色・フォントを外部から読み込んで寄せる点は [[design/design-md]] の「デザイン仕様を `.md` に置いてエージェントに参照させる」を、ファイルでなく実サイトを参照元にした形と読める。

なおMermaidのようなテキスト記法との違いは、記法の表現力でなく**最終出力の見た目を制御対象に含めるか**にあると考えられる。このvaultのwikiページが使うMermaidは構造の伝達に振り切っており、ブランド適合は範囲外である。
