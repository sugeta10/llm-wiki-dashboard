# FFmpeg Skill（AIエージェント向け動画処理スキル）

@kebura_Pが2026-09-04に「FFmpegをAIエージェントからちゃんと使えるようにするSkill」を作ったと発表した。利用者は自然言語で指示するだけで、SkillがFFmpeg（動画・音声の変換CLI）とffprobe（メディア情報の解析CLI）を使って処理する。同氏が挙げる指示の例は次の5つである（ソースからの転記）。

- 「この動画を9:16にして」
- 「無音部分をカットして」
- 「字幕を入れて」
- 「iPhoneのHDRをSDRにして」
- 「X向けに書き出して」

同氏は「単なるコマンド集ではなく」と続けるが、ソースの本文はそこで途切れており、何を加えたのか（判断基準・検証手順・失敗時の対処など）、スキルの正式名称、リポジトリURLは未収集である。

[[tools/video-use]]（素材フォルダを渡してClaude Codeと会話しながら無音カット・字幕・カラー調整を行うOSS）と用途は重なるが、こちらは独立したツールでなくエージェントに読ませるSkillという形態を取る、と同氏の説明から読める。[[tools/claude-real-video]]は内部でffmpegのシーン変化検出を使って動画をLLMに「見せる」前処理器で、方向が逆（見る／編集する）である。

## 問い

- 「単なるコマンド集ではなく」の続きを確認する。手順の列挙に何を足すとエージェントがFFmpegを「ちゃんと」使えるようになるのか、[[papers/2026-li-skillsbench]]のSkillあり/なし対試験の枠で差が出る要素か
- [[tools/video-use]]との使い分け。既存の編集ツールを入れるより、手元のFFmpegをSkill経由で叩く方が軽い場面はどこか
- iPhoneのHDR→SDR変換はFFmpegではトーンマッピングの指定が要る。Skillが実際にどのコマンドを出すかを確認する

## 関連

- [[tools/video-use]] — 同用途（無音カット・字幕）の先行OSS。ツール本体を持つ点が対照
- [[tools/claude-real-video]] — 逆方向：ffmpegで動画をLLM可読な中間形式に整えて「見せる」前処理器
- [[tools/akari-video]] — コーディングハーネスを活用する動画編集OSS。同系統の別アプローチ
