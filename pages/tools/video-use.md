# video-use

Claude Code に動画編集をさせるオープンソースのツール。紹介者の @opensourcelab9（二次まとめ系アカウント）によれば、素材フォルダを渡して Claude Code と会話しながら編集を進めると、フィラー語（「えー」「あー」等のつなぎ言葉）や無音区間のカット、字幕やカラー調整までを行い、最終的に `final.mp4` を返す。

コーディングエージェントをそのまま動画編集者に転用する点で [[tools/openmontage]]（リサーチ→脚本→素材生成まで含むエージェント型動画「制作」システム）と同系の発想だが、video-use は手持ちの実写素材の「編集」に焦点がある。名前は [[tools/browser-use]]（ブラウザを AI に操作させるライブラリ）の命名系譜を踏んだものと考えられる。逆方向のツールとして、動画を Claude Code に「見せる」前処理器 [[tools/claude-real-video]] がある（あちらは見る、こちらは編集する）。
