# Claude Code サブエージェント

> **TL;DR**: [[tools/claude-code]] のサブエージェント機能は、専用のコンテキストウィンドウで独立動作し、ツール呼出のノイズをメインに残さず結果サマリーだけを返すことで、長セッションのコンテキスト汚染を防ぐ仕組み。

長いセッションでは grep・find・ls といった探索系ツールの呼出や中間ファイルの読込がすべてメインのコンテキストに蓄積し、ノイズになる。さらに `/compact` 時にはこの蓄積が原因で重要情報が圧縮で失われやすい。サブエージェントはこの問題を、探索系の呼出や中間読込をサブエージェント側のコンテキストに閉じ込めることで構造的に防ぐ。メインに戻るのは最終的な結果サマリーだけなので、親のコンテキストは汚染されない。

**定義方法**: サブエージェントは `.claude/agents/`（プロジェクトローカル）または `~/.claude/agents/`（グローバル）に Markdown ファイルとして置く。frontmatter の `description` などを Claude Code が自動検出し、タスクが説明に一致すると起動する。優先度は「プロジェクトローカル > グローバル」で、同名定義がある場合は高優先度側が勝つ。チーム共有はプロジェクトローカル、個人用途はグローバルに置くのが使い分けの基本。

**起動時のコンテキスト**: デフォルトのサブエージェントは空コンテキスト（クリーン）で起動する。環境変数 `CLAUDE_CODE_FORK_SUBAGENT=1` を設定すると、親コンテキストの完全コピーを引き継ぐフォーク起動になる。オンデマンドでフォークする場合は `/fork` スラッシュコマンドを使う。

```bash
export CLAUDE_CODE_FORK_SUBAGENT=1
```

フォークされたサブエージェントの特性：

- 親の会話全体をフォーク時点で継承する
- 親とプロンプトキャッシュプレフィックスを共有する
- ツール呼出は親のコンテキストに入らない
- 最終サマリーのみを親に返す

## Built-in サブエージェント

Claude Code には以下のサブエージェントが同梱されている。

| サブエージェント | 役割 |
|--------------|------|
| **Explore** | コードベース検索（grep/find 系）を独立コンテキストで実行。関連箇所だけを返す |
| **Plan** | ファイル読込・アーキテクチャ理解・実装計画を作成。中間ファイル読込がメインに入らない |

## 問い

- `CLAUDE_CODE_FORK_SUBAGENT=1` のフォーク起動は、空コンテキスト起動と比べて実タスクでどちらが安定するか自分のワークフローで試す
