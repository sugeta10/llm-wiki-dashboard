# claude plugin eval（プラグイン・スキルの効果測定コマンド）

Anthropic 公式（@ClaudeDevs）が2026-09-11に、[[tools/claude-code]] の新機能として `claude plugin eval` を発表した。同アカウントはこのコマンドの目的を「自分のプラグインがどれだけの価値を足しているのか、それとももっと手を入れる必要があるのかを見る」ことだと説明している。

同アカウントが挙げる手順は次の4つ（ソースからの転記）。

1. テストケースを作る
2. プラグインまたはスキルをテストケースに対して走らせる
3. その実行を採点する
4. 各ケースをプラグイン**なし**でもう一度走らせ、差分を見る

核心は4番目の「なし」の再実行が手順に組み込まれていることで、スキルやプラグインを足したこと自体の寄与を分離して測る形になっている。これは [[papers/2026-li-skillsbench]] が同一タスクをSkillあり・なしで走らせて差分を取る対試験（paired evaluation）と同じ構造であり、研究側で提案された測り方が一次ツールとして降りてきたものと考えられる（ソースはSkillsBenchに言及していない）。

コマンドの具体的な使い方——テストケースの記述形式・採点器の指定方法・出力形式・プラグイン単位かスキル単位かの粒度——はソース本文に含まれず、添付画像の内容も未捕捉のため未収集である。

## 問い

- テストケースと採点はどこまでコマンドが用意し、どこから自分で書くのか。[[concepts/eval-loop]] の3要素（テストケース・採点基準・閾値）との対応を確認する
- このwikiの wiki-ingest スキルをこのコマンドにかけられるか。カテゴリ判定・粒度判定のような決定論的に採点しにくい出力に、あり/なしの差が出る採点器を組めるか
- 手元の `.claude/skills/` を1本ずつ外して測ると、どれが実は効いていないか。SkillsBench の「2〜3個で最大・4個以上で劣化」「自己生成スキルは逆効果」が自分の環境でも再現するかを確かめる入口になる
