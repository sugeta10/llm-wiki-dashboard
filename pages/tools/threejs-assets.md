# threejsassets.com の無料 3D アセット

**threejsassets.com**（@threejsassets）が three.js・React Three Fiber・その他の WebGL レンダラ向けに配る、無料で商用利用もできる低ポリの GLB モデル群。X の告知（2026-10-24）では「937 点の無料 3D アセット、次のゲームにそのまま入れられる」とあり、配布ページのキャッシュ（2026-10-28 取得）では 959 点・毎週更新と表示されている。

配布ページ（サイト運営者の記載）の条件:

- 無料アカウントでダウンロード。クレジットカード不要、帰属表示（attribution）不要、プロジェクト単位で追跡すべきライセンスもない
- 同社のアセットライブラリから引いたもので、低い品質基準で別に作ったものではない、と主張
- 各カードに現在の三角形数と圧縮後ファイルサイズが載るので、シーンの予算（budget）を決める前に確認せよ、と案内

告知の添付は動画のサムネイルのみで、素材の見た目や内訳（カテゴリ・スタイル）は未収集。

wiki 側の見方（推論）: [[tools/hyperframes]] のように LLM が HTML/JS で動画や演出を書く流れや、[[tools/loop-library]] にある「three.js で9アングルを採点して反復改善する」ループでは、モデルを自作せず GLB を置くだけで読み込める素材の有無が制作の速さを決める。[[design/lusion]] が示す「動きと3D演出に価値が置かれる Web 体験」を個人やエージェントが真似るときの、素材側の供給源にあたると考えられる。

## 問い

- カードの三角形数・ファイルサイズをプログラムから取れる API や一覧があるか。あれば、エージェントに予算内のモデルを選ばせる入口になる
- Claude Code に three.js のシーンを書かせるとき、GLB の URL を渡すだけでローダー込みで動くコードが出るか。アカウント必須の配布条件が自動取得の妨げにならないか
