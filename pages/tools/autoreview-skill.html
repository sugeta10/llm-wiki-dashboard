autoreview スキル

openclaw の agent-skills リポジトリに含まれるコードレビュー自動化スキル。ローカル変更・ブランチ・PRを対象に構造化されたレビューを実行するクローズアウトチェック用ツール。Codex がデフォルトエンジン（最良結果）。

観察ログ（未検証）

  • 2026-05-28: レビュー出力は「助言」扱い。すべての指摘を実際のコードパスで検証し、非現実的なエッジケース・投機的リスク・広範なリファクタリング提案は拒否する設計
  • 2026-05-28: セキュリティ監査抑制変更は「抑制済み指摘」を構造化出力に残すことで、有効出力が無関係なリスクを隠さないよう保証する
  • 2026-05-28: --parallel-tests でテストとレビューを並行実行し、どちらかが変更を引き起こした場合は再実行する
  • 2026-05-28: 最大30分間実行可能（大きなバンドル時）。30分未満のサイレント期間でプロセスを強制終了しない
  • 2026-05-28: --stream-engine-output でライブエンジン出力をストリーミング可能（Codex/Claudeはツールイベントとファイルイベントをフィルタリングし、コンパクトサマリーを出力）

検証済み事実

  • 2026-05-28: デフォルトエンジンは Codex（環境変数 AUTOREVIEW_ENGINE で切替可能）
  • 2026-05-28: --reviewers codex,claude または --panel で複数エンジンレビューパネルを実行できる
  • 2026-05-28: ヘルパーは stdout のみに出力し、--output / --json-output 指定時以外はファイルを書かない

主なモード

モード コマンド例 用途
ローカル変更 autoreview --mode local ステージ済み・未ステージの変更
ブランチ/PR autoreview --mode branch --base origin/main ブランチとの差分
単一コミット autoreview --mode commit --commit HEAD 着地済み・push済み作業

レビューパネル

複数エンジンを1つの冷凍バンドルに対して実行できる。

autoreview --reviewers codex,claude --model codex=gpt-5.1 --thinking codex=high --model claude=sonnet --thinking claude=max

Codex は model_reasoning_effort（low/medium/high/xhigh）、Claude は --effort（max まで対応）にマッピングされる。

Contract（要約）

  • 指摘はすべて実コードで検証してから適用する
  • セキュリティ指摘は具体的・実行可能なリスクのみ報告
  • ネストされたレビュー・別のエンジン呼び出しは禁止（ヘルパー内部で行う）
  • アクション可能な指摘がゼロで exit 0 が出たら停止。追加確認レビューは不要
