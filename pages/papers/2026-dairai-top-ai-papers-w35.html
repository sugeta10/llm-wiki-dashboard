DAIR.AI 週間トップAI論文（2026-08-24〜30）

TL;DR: DAIR.AI（@dair_ai）選定の週次トップ10論文。LLM-judge運用・スキル評価・コンテキスト管理・生成ハーネス・自己改善エージェントと、モデル本体でなく「エージェントの周辺系」の研究が10本中9本を占めた週。

以下は各論文のdair_aiによる要約からの転記で、原論文は未参照。モデルアーキテクチャの新提案が1本もなく、判定器・ハーネス・メモリ・スキルライブラリといった運用層の研究で埋まった点に、研究の重心移動が表れていると考えられる。

10本の要旨

  1. Judges as a Lifecycle（Netflix） — LLM judgeを一度検証して終わりにせず、Birth（基準定義・人手ラベルのベンチマーク構築）→ Training（ルーブリック改善）→ Deployment → Monitoring（ドリフト監視・再チューニング）の4フェーズで運用する。メタジャッジがjudgeの推論出力を学習信号にするReasoning-Aligned Rubric Tuningで、人間との不一致をルーブリックの文言に遡って修正する。週数十万件の推薦説明文に適用し、数千万会員への5週間A/Bテストで未視聴コンテンツへの視聴シフトとbrowse-to-play成功増を確認したとdair_aiは紹介する。
  2. Skill Lift（NVIDIA・ACES） — スキルの構造・スタイル・セキュリティを検査するスキャナーのスコアは、LLM-judge品質とSpearman rho 0.14でほぼ無相関。代わりに同一モデル・サンドボックス・スコアラーでスキルあり/なしを対で走らせ差分（Skill Lift）を測ることを提案。58本番スキル・947ペアケースを4ハーネス横断で採点し、軌跡をAgent Trajectory Interchange Formatで正規化して比較可能にした。2026-li-skillsbenchと同じ対試験パラダイム。
  3. Scroll（Alibaba） — メモリスキーマを設計せず、コンテキスト構築をモデルのプログラミング問題として渡す。append-onlyイベントログ＋サンドボックス化された永続Pythonカーネルに状態を置き、モデルが書くコードで検索・変換し、明示的にprintした射影だけがプロンプトに入る。退避された領域も回復可能。Qwen3.8-MaxでLongMemEval_S 94.8%・BEAM_10M 73.1%（既存メモリシステム比+5.1pt）・LOCA_256K 86.7%。
  4. JIT-Agent — 出力がハーネスそのものであるモデル。memory / planning / action protocol / tool orchestrationの4モジュールプロトコルの下でタスクごとにハーネスを合成し、実行中に修復、過去構成のアーカイブから自己進化する。DeepSeek-V4-FlashがDeepSearchQAでGPT-5.6を+9.1pt上回り、GLM-5.2は最大+20.2pt。生成ハーネスはOpenCodeやClaude Codeと性能競争力があるとdair_aiは紹介する。
  5. Prime Agent（Prime Intellect） — 長期ホライズン作業向けのオープンソースハーネス。永続IPython REPLでモデルがコンテキストをコードで処理し、履歴・記憶・スキル・プロンプト・サブエージェント仕様が走行間で永続するContinual Harnessを持つ。ARC-AGI-3のRHAE Best@1がモデル据え置きで30%→95.5%。
  6. What Compaction Destroys — 20の本番エージェント構成でコンテキスト圧縮が壊すものを測定。安全ルールとエピソードログが同じトークン予算を奪い合い等しく圧縮されるため、正確な文言を要する安全ルールが最初の犠牲になる。Claude Code compact（Sonnet 4.6）は1回で53%、5回で10%しか安全ルールを保持しない。対策のKnowledge Triageは知識を型分類し型別の保持ポリシーへルーティングして2〜4倍の保持と5ラウンド96% recallを達成。
  7. Co-Scientist in Real Labs（Google DeepMind） — Co-Scientistを物理実験へ。MXenesの安全な前駆体ルートを設計し半自動CVD反応器を運転、単層MoS2等の単回試行成長を実現。HealthBench Hardでは発見した推論時スケーリングアーキテクチャが盲検医師レビュー下で6つのフロンティアモデルを上回った。30人の専門家が450本のレビューを書き、信頼性モジュールが幻覚と剽窃を測定可能に減らした。
  8. Recuris — エージェントメモリをWorking Memory（タスク進捗）とExperiential Memory（スキル）に二分し、スキル選択を成長し続ける全履歴でなく現在のタスク状態に接地させる。固定Meta-Agentが失敗の証拠を検証ゲート付きのSkill Memory更新に変換。37構成中35で改善、tau-benchでGPT-5.6 Solに+17.8pt。
  9. Meta^n — 自己編集システムは自らの編集機構の一部を固定せざるをえず実効メタ深度が約2で頭打ちになる問題に対し、メタ操作を固定して入力側に再帰させ、収束が深度を決める設計。8ベンチマークファミリー全てで先行自己改善エージェントを上回り、ARC-AGI-2で唯一ゼロ超えのスコア。
  10. EvoMal — 共有スキルライブラリのマルウェア伝播を実証。植え込まれた悪性スキルは一度も呼び出されずとも著述テンプレートとして参照され、エージェントがペイロードを保存した新スキルを書いてライブラリに再投入する。6モデルで自己中毒率20.3〜41.8%、植えたスキルを全削除しても除去できず、バナー式コピーを抑止するカウンタープロンプトで6.7%まで低下。
